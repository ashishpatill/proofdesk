# KiteMetric (fictional company, sample data)

KiteMetric is a fictional product-analytics SaaS used as sample data
for ProofDesk. Every fact below is invented for the demo; the point
is that questionnaire answers must trace back to these documents and
nothing else.

- Founded 2021, headquartered in Bengaluru, India.
- 42 employees, all in India.
- Product: product analytics for web and mobile apps (event tracking,
  funnels, retention reports).
- Hosting: Amazon Web Services, ap-south-1 (Mumbai) region only.
- Customers: about 300 companies, mostly India and South-East Asia.
- Deployment model: multi-tenant SaaS. KiteMetric does not publish
  any other deployment option in these documents.
